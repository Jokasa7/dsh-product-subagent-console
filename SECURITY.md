# Security Policy

## Supported versions

Only the latest published release is supported. This project is currently an alpha preview and may receive breaking updates.

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Jokasa7/dsh-product-subagent-console/security/advisories/new). Do not include credentials, private prompts, task output, or personal data in a public Issue.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/Jokasa7/dsh-product-subagent-console/issues).
