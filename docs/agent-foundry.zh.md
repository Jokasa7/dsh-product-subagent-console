# Agent Foundry

[English](agent-foundry.md)

Agent Foundry 会把已批准方案与 DSH 权威生命周期组合成可核验证据视图。入口位于**子代理 → 偏差**和**子代理 → 恢复**。

## Execution Twin

画布会明确区分计划任务与实际 attempt。只有执行快照包含完全一致的 `planId`、修订、任务和 attempt 绑定时，二者之间才会出现连线。选择节点后，可在 Evidence Passport 中查看：

- 生命周期与一致性状态；
- 计划角色、effect 合同与依赖；
- 实际 attempt、已记录的 Provider/模型配置（如可用）与耗时；
- 验证器回执及其引用事件；
- 未关闭发现与首个可证明偏差；
- 稳定的 run、plan、cursor 和投影标识。

## 时间回看

拖动**运行时间轴**可按较早的事件游标重建运行状态。暂停时：

- 新的实时事件不会移动当前游标；
- 画布、回执、发现和 Ask 请求都使用该精确游标；
- Capsule、遥测和恢复操作会被禁用，因为这些操作要求最新事实。

选择**返回实时**即可回到最新游标。

## 询问本次运行

选择事实查询类型，可选中具体任务或 attempt，然后输入问题。点击**发送到当前对话**后，插件会把有界、白名单化的事实包发送到该对话，因此也会交给该对话配置的模型 Provider。事实包不会附带原始对话全文、模型完整输出、stderr、环境变量或隐藏推理。

查询类型包括摘要、为什么仍在运行、首个偏差、活动任务、已记录配置、取消影响、恢复影响和验证证据。配置事实只来自 DSH 权威事件，或 Workflow 适配器实际应用并以 `adapter` 权威记录的 transport、模型路由与工具策略；插件不会把方案字段冒充成运行时观测，无法证明的字段保持未知。

## 恢复预演

恢复模式会基于当前一致性报告展示受影响任务、可复用且已完成的验证任务、阻塞原因，以及 Retry 或 Fork 建议。在 DSH `0.1.1-rc.2` 中，这些建议不会自动执行。

只有当前、未结束的 Workflow 执行才能请求取消整个运行。用户需要连续进行两次可见确认，随后 Host 才会签发一个短时效、一次性的 grant；它精确绑定 Session、run、proposal、方案修订、能力摘要和事件游标。出现任何新的运行事件后，旧 grant 会失效。

同一 DSH Profile 内的 loopback Web Client 属于本地信任边界。当前 DSH 公共连接 API 不会向插件 RPC handler 提供已认证的调用者 Session，因此该 grant 用于防止误触和陈旧操作，而不是抵御恶意的已安装本地插件。

## Run Capsule

**导出运行 Capsule**会生成自包含的离线 HTML 查看器与 Manifest。标识会被假名化，字段采用白名单，证据引用保持闭合，大型运行会按确定性规则限制体积。默认不包含目标与任务 brief；分享前仍应自行检查导出文件。

Manifest 会记录自身摘要、源数据与导出数量、脱敏策略、方案合同、执行投影、一致性发现、恢复预演、有界事件与验证器回执。

## Recipe 候选

选择至少三次运行，然后点击**检查历史运行**。只有全部运行同时满足以下条件时，才会生成候选：

- 使用同一个可比的规范化方案合同；
- 使用相同能力摘要与验证器套件；
- 成功结束，且一致性状态为 `confirmed`；
- 不存在仍打开的阻塞性一致性发现；
- 每个必需验证器都有非模型权威通过回执，并且引用的是该运行自己的证据事件。

候选会记录方案模板、权限配置、预算范围、能力要求和源运行摘要。插件不会根据历史记录猜测工具隔离：继承权限保持“未解析”，显式 allowlist 在新草稿完成当前环境预检前也只标记为“未证明强制执行”。

输入新目标并点击**创建草稿、预检并打开方案**。该操作只创建新草稿并执行当前预检，不会批准或执行。导出候选会下载一份 ZIP，其中包含 `recipe.json`、`SKILL.md` 和 `checksums.json`，但不会安装它们。单一压缩包可避免浏览器拦截连续多文件下载，并保持三份已审查文件始终成组。

## 单 Agent / 多 Agent 对比建议

对比器只按实际创建出的任务 Agent 分类，不相信方案中的 pattern 标签。形成建议前，至少需要三次已验证的单 Agent 运行和三次已验证的多 Agent 运行，并且它们拥有相同的最终工作语义、执行配置、能力摘要和验证器套件。全部门禁通过后才比较中位耗时；只有一组中位耗时至少低 10% 时才显示方向，否则结果为 `no-claim`。缺失或不可比的证据一律显示证据不足。

## 遥测预览

OTLP JSON 导出默认关闭。只有在插件配置中显式启用后，才会生成有界的离线 JSON 预览；插件不会配置或连接任何遥测后端。

本地存储、脱敏与清理方式见[数据与隐私](data-and-privacy.zh.md)。
