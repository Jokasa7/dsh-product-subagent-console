# 完整功能演示

[English](product-tour.md) · 简体中文

本页用一个有明确边界的多 Agent 任务，展示从方案设计到证据复用的完整流程。所有操作都在当前 DeepSeek Harness 对话的**子代理**页签中完成。

## 1. 把目标变成可审核方案

打开**方案**，描述目标并生成草稿。启动任何子 Agent 之前，画布就会展示角色、职责、任务、依赖、Provider、工具、验证合同与整体预算。

![可编辑的 Agent 方案与任务依赖](assets/agent-plan-zh.jpg)

选择任务后，可以收紧任务说明、完成标准、资源声明、影响类型和必需验证器。保存指定修订并运行预检；能力、依赖、并发或预算存在阻塞问题时，必须先修正才能批准。

批准只会锁定该修订和对应能力摘要；真正启动仍需要一次独立且可见的确认。

## 2. 在实时模式跟随真实委派

**实时**按照真实父子关系展示原生子会话和兼容 Provider 运行。每张卡片概括当前职责与生命周期；选择卡片可以查看详细事实，并在可用时打开原生子会话。

![真实父子任务画布](assets/agent-runtime-zh.jpg)

拖动卡片、平移、缩放、适应视图或自动排列只改变浏览方式，不会改变执行。即使分支较多，画布也会优先保持运行中任务可见。

## 3. 重建实际发生过什么

执行开始后打开**偏差**。Execution Twin 会把批准方案中的任务映射到真实 attempts，并把缺失、意外、重试、取消和完成状态分别保留为事实。

![批准方案与真实 attempts 的映射](assets/agent-compare-zh.jpg)

拖动时间轴游标即可暂停在历史事件。暂停后，图、当前节点、Evidence Passport 和一致性发现都会按该游标重建，不会混入后来发生的事实。

Evidence Passport 会分开回答四个问题：

- 批准的方案要求了什么？
- DSH 实际报告了哪个 Provider、模型、attempt 与生命周期？
- 哪些权威验证回执支持结果？
- 如果存在偏差，首个可证明偏差是什么？

## 4. 带着证据直接询问运行

选择**为什么仍在运行**、**首个偏差**、**已记录配置**、**取消影响**或**验证证据**等事实查询，补充自己的问题后发送到当前对话。配置事实只来自 DSH 权威事件或 Workflow 适配器实际应用的路由字段；不可观测的字段会保持未知。

插件会附上有界的事实包，包含精确 Session、运行、任务、事件游标、事件 ID 和回执 ID；不会让模型虚构隐藏进度或产品内部 Agent 状态。

## 5. 控制之前先预演恢复影响

**恢复**会区分受影响、可复用和被阻塞的任务，并给出 Retry 或 Fork 建议。v0.9 中这些建议不会自动执行。

当前唯一真正可执行的控制是取消整个运行。它需要两次明确点击和一个绑定当前运行及事件游标的短时授权，最终结果还必须写入事件账本。运行事实变化、页面停在历史游标、授权过期或 Host 重启时，控制都会安全拒绝。

![恢复影响预演、可复用任务与受保护的控制](assets/agent-recovery-zh.jpg)

## 6. 安全复用运行证据

- **Run Capsule** 下载一份有大小上限、默认脱敏的离线 HTML 报告。分享前仍应人工检查；目标和任务说明默认不包含在内，只有 API 调用方显式请求时才会加入。
- **Recipe** 至少需要三次完全可比且验证通过的运行，候选会记录方案合同、Provider 要求、权限不确定性、验证器套件和预算边界，并导出为一份便于审查的 ZIP。
- **创建草稿**只绑定新目标，在当前环境重新预检并打开方案；不会自动批准或执行。
- **单 Agent / 多 Agent 对比建议**只有在两组都具备足够可比、已验证样本时才会给出方向，否则明确显示证据不足。
- **OTLP JSON 预览**只生成本地文件且默认关闭，插件不会启用网络导出器。

## 一次安全的完整测试

使用已启用方案工具的新对话，输入：

> 请为当前工作区设计一个只读的三任务方案：任务 A 只读取 README.md 第一段，任务 B 只读取 package.json 的 name 和 version，两者并行；任务 C 只基于两者结果输出三行汇总。每个任务得到目标结果后立即停止。只生成草稿，不要执行。

然后依次完成：

1. 在**方案**检查任务边界和上下文依赖；
2. 保存、预检并批准指定修订；
3. 单独确认执行请求；
4. 在**实时**观察真实分支；
5. 在**偏差**暂停游标，并查看某个任务的 Evidence Passport；
6. 在当前对话询问首个偏差或验证证据；
7. 打开**恢复**查看影响预演，但先不发送控制；
8. 导出 Capsule，并在分享前检查本地文件。

安装和预设配置见[入门指南](getting-started.zh.md)，字段与当前执行边界见[Agent 方案设计器](agent-planner.zh.md)，Foundry 证据语义见[Agent Foundry](agent-foundry.zh.md)。
